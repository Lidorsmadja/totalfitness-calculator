# מחשבון מתחם כושר · טוטאל פיטנס

דף נחיתה לקמפיין: הלקוח בוחר סוג מקום, גודל וציוד, רואה הדמיה חיה, משאיר שם וטלפון, מקבל מחיר משוער, מגרד כרטיס הטבה ועובר לוואטסאפ עם מספר ההצעה.

## מבנה הפרויקט

| קובץ | מה יש בו |
|---|---|
| `index.html` | כל האתר: המחשבון והפאנל האחורי, בקובץ אחד |
| `favicon.svg` | אייקון הלשונית, מתוך הלוגו |
| `apps-script/Code.gs` | שרת הלידים על Google Sheets |

## עבודה מקומית ב-VS Code

1. פותחים את התיקייה ב-VS Code.
2. מתקינים את התוסף **Live Server** ולוחצים על **Go Live**, או מריצים בטרמינל:
   ```
   npx serve .
   ```
3. המחשבון: `http://localhost:5500` (או הכתובת ש-serve מציג)
4. הפאנל האחורי: אותה כתובת עם `#admin` בסוף

## חיבור הלידים לגוגל שיטס (פעם אחת, כ-5 דקות)

בלי החיבור הזה ליד נשמר רק בדפדפן שבו הוזן, והפאנל האחורי מציג רק לידים מאותו דפדפן.

1. פותחים Google Sheet חדש ← **תוספים** ← **Apps Script**.
2. מוחקים את הקוד הקיים, מדביקים את כל התוכן של `apps-script/Code.gs` ושומרים.
3. **הגדרות הפרויקט** (גלגל השיניים) ← **Script Properties** ← מוסיפים מאפיין:
   `ADMIN_KEY` = קוד הכניסה לפאנל האחורי. בחרו קוד חזק.
4. **Deploy** ← **New deployment** ← סוג **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
5. מאשרים הרשאות ומעתיקים את כתובת ה-Web app.
6. ב-`index.html` מחפשים `sheetUrl: ""` ומדביקים את הכתובת בין המרכאות.
7. מעלים מחדש לשרת.

מעכשיו כל ליד נכנס לגיליון "לידים" ברגע שהלקוח מזין שם וטלפון, גם אם לא סיים את התהליך. הפאנל האחורי (`#admin`) מבקש את קוד הכניסה, ומתעדכן כל 20 שניות. הערות הצוות נשמרות בגיליון "טיפול צוות".

## עדכון מחירים וציוד

ב-`index.html` מחפשים `const CATALOG`. לכל פריט:

- `price`: מחיר ליחידה בש״ח
- `need`: כמה מ״ר הפריט תופס כולל מעברים. הערכים מכוילים ל-15 פריטים ב-50 מ״ר ו-8 מיטות פילאטיס ב-50 מ״ר.
- `name` ו-`desc`: הטקסט שהלקוח רואה

מעל הרשימה, ב-`CONFIG`:

- `floorPerSqm`: מחיר ריצוף למ״ר
- `installRate`: הובלה והתקנה כאחוז מהציוד (כרגע 5%, הערכה)
- `whatsapp`: מספר הוואטסאפ שאליו נשלחת ההודעה

### מקור המחירים

המחירים נלקחו מ-totalfitness.co.il באוקטובר 2026. הערכות שלא מופיעות באתר: סט משקולות (₪5,900, באתר יש רק סטנד ב-₪2,900), חבילת אביזרים (₪2,900), והובלה והתקנה (5%).
